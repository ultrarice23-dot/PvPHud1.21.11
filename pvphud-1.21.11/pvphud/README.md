# PvP HUD (Fabric, client-side) for Minecraft 1.21.11 (Yarn 1.21.11+build.4)

Build on GitHub: push the files, open Actions tab, download the `pvphud-jar` artifact.
Put the jar in the mods folder of a Fabric 1.21.11 profile (Fabric Loader + Fabric API).

Keys (rebindable in Controls > PvP HUD)
  \  settings + HUD editor   [  start / reset   ]  pause   '  resume
Config: .minecraft/config/pvphud.json
